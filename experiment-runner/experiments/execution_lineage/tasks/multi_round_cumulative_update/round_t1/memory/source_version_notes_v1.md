# Source Version Notes

Older reimbursement notes argued that instability was severe enough to keep
telehealth growth in pilot mode.

After revision, that older framing is too strong for the targeted behavioral-
health and chronic-care follow-up lines. The newer state is more conditional:
selected parity support now exists for those lines, but not for all services,
payers, or geographies.

Some earlier notes and draft language may still reflect the stronger pilot-only
caution, so treat remembered reimbursement summaries carefully.
